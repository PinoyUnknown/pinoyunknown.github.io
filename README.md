## 🛰️ Architectural Overview

**PINOYUNKNOWN** is an advanced cyberpunk-themed cyber-defense dashboard, telemetry inspector, cryptographic toolkit, and in-repository offline artificial intelligence assistant. Designed for security researchers, reverse engineers, and developers, the application operates **100% client-side** directly inside the browser sandbox, requiring **zero backend servers, zero external API keys, and zero token billing**.

### 🌟 Core Highlights
1. **In-Repository Offline AI Assistant (`archangel-llm.js`):** A lightweight, self-contained neural knowledge engine stored directly inside the GitHub repository. Runs completely offline in client memory with zero token costs and zero latency.
2. **Comprehensive 26-Tool Cryptographic Utility Suite:** A complete payload transformation, hashing, encryption, deobfuscation, and entropy analysis toolkit.
3. **Deep Environmental Telemetry Exploration:** Unmasks WebGL GPU hardware driver pipelines, CPU multi-threading concurrency, memory allocation, and screen depth geometry.
4. **Automated VPN / Cloudflare / Proxy Threat Flagging:** Real-time routing inspection testing ISP gateways against known hosting arrays, VPNs, datacenters, and Tor exit nodes.
5. **Interactive Hardware Threat Audit Scanner:** Multi-stage terminal log simulation inspecting file trees, temporary cache registers, memory boundaries, and `.gitignore` leak policies.
6. **Web Audio Synthesizer Engine:** Dynamic procedural glitch sounds and telemetry data blips synthesized via the Web Audio API without external audio media files.
7. **Matrix Rain Canvas Overlay:** High-FPS procedural katakana and alphanumeric rain animation running in background canvas layers.

## 🔍 Target Environmental Telemetry

The telemetry engine actively queries client hardware and network vectors:

- **CPU Cores:** Reads `navigator.hardwareConcurrency` to map client multi-threading pools.
- **RAM Allocation:** Evaluates `navigator.deviceMemory` (GB limits in supported browsers).
- **Display Topology:** Queries `screen.width`, `screen.height`, and `screen.colorDepth`.
- **Unmasked WebGL GPU Renderer:** Queries the `WEBGL_debug_renderer_info` WebGL extension to reveal exact graphics card hardware models (NVIDIA, AMD, Intel Iris/HD) bypassing standard generic driver masks.
- **Network Geolocation & ISP Routing:** Fetches IP and Autonomous System (AS) routes via `ipapi.co/json/` with automatic fallback to `ipwho.is/` and offline loopback resolution.
- **Proxy / VPN / Cloudflare Detection:** Inspects organization headers for signatures including `CLOUDFLARE`, `DATACENTER`, `VPN`, `DIGITALOCEAN`, `HOSTING`, `AMAZON`, `GOOGLE`, `MICROSOFT`, and `TOR`.

## 🔒 Browser Sandbox & Client Security Boundaries

In compliance with modern web application security guidelines:
- **Sandbox Isolation:** Web browsers enforce strict client sandboxing. Client-side JavaScript cannot access local file systems, CPU thermal sensors, or arbitrary host memory without explicit OS permission.
- **Credential Protection:** Client-side static websites hosted on GitHub Pages **must not** embed GitHub Personal Access Tokens (PATs) or private API keys directly in source code. Any token committed to a public frontend repository is exposed to inspection.
- **Manifest Export:** Because browsers cannot silently push files back into Git repositories, the **"Save Logs"** action downloads a timestamped `.txt` manifest file directly through the client's file manager while simultaneously copying the report to the system clipboard.
